# .github

このリポジトリは org の [デフォルトコミュニティヘルスファイル](https://docs.github.com/ja/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization) を提供する。

- `.github/ISSUE_TEMPLATE/`: appetite欄付きの汎用Issueテンプレート。個別リポが独自のISSUE_TEMPLATEを持たない場合に自動適用される
- `docs/INCIDENT_TEMPLATE.md`: インシデント記録の5項目テンプレート(症状/初動/根本原因/再発防止策/横展開先)。GitHub側の自動継承対象外のため、各リポからは手動でリンク参照する

正本の背景・設計判断は flipslidersand-labs/qa-workflows#37 を参照。
